🚆 Nearest-station finder — settings

For Bangladesh Railway e-ticketing (eticket.railway.gov.bd). When your route is sold out, the finder re-queries the railway API for the stations just before / after your origin and destination — plus the nearest stations by road distance — and lists everything that still has seats.

Search behaviour

hops = how many stops up/down the train's route to consider (route based). Distance-based neighbours adds stations that are simply close by, even if no train on your route stops there.

Station name fixes

The bundled timetable occasionally spells a small station differently from the booking site. If a pair keeps returning “no trains”, add the site's spelling here — one per line, CODE = Site Name (the code is shown in the panel, e.g. TEJ = Tejgaon).

Connection test

Runs one real query against the railway API using your current session. Open eticket.railway.gov.bd and log in first.
